WENZEL HAULAGE TARIFF WEBSITE

Files:
- index.html: responsive tariff search/calculator
- tariffs.json: tariff data extracted from the supplied Wenzel 2026 PDF
- Wenzel-Request-for-Transport.pdf: ROT form
- Wenzel-Haulage-Tariff-2026.pdf: full tariff source PDF

To publish as a public link using GitHub Pages:
1. Create a GitHub repository, e.g. wenzel-haulage-tariff-2026.
2. Upload ALL four files (plus this README is optional) into the repository root.
3. In Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
4. GitHub will provide the public URL, typically https://YOUR-USERNAME.github.io/wenzel-haulage-tariff-2026/

Please verify the displayed rates and calculation settings before public release. FAF is initialized at 19.71%, DGC at RM55, discount at 0%.
